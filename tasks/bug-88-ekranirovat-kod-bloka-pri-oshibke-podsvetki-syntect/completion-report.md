# Итог задачи: Экранировать код блока при ошибке подсветки syntect

- Issue: #88
- Итоговое состояние: реализовано, все ворота пройдены

## Реализованные требования
- FR-1: свой адаптер `Highlighter` в `crates/nimmd-core/src/render.rs` вместо `SyntectAdapter` для блоков кода и frontmatter; вывод при успешной подсветке побайтно прежний.
- FR-2: при `Err` syntect блок выводится целиком через `html::escape` (`write_highlight_or_escaped`).
- FR-3: `syntect` 5.3 — прямая зависимость (`default-syntaxes`, `html`, `regex-fancy`), у `comrak` снята фича `syntect-fancy` (ARCH-001); из `Cargo.lock` ушли зависимости тем и iOS/wasm-ветки.
