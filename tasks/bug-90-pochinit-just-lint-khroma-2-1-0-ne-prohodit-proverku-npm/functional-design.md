# Функциональный дизайн: Починить just lint: khroma 2.1.0 не проходит проверку npm-лицензий

## Метаданные [@for: all]
- Issue: #90
- Size: S
- Владелец: Системный аналитик

## Цель [@for: all]
- `just lint` зелёный в CI: пакет без поля `license`, но с лицензией из белого списка, проверенной вручную, проходит проверку по явному уточнению с версией (как `[[licenses.clarify]]` в `deny.toml`).
- Причина: у `khroma@2.1.0` (транзитивная зависимость Mermaid) в `package.json` нет `license`; pnpm в CI отдаёт `Unknown`, локально у разработчика — `MIT` (по файлу `license`). Лицензия пакета — MIT (файл `license` в fabiospampinato/khroma).

## Границы [@for: all]
- Входит: FR-1…FR-3 в `scripts/check-npm-licenses.mjs`.
- Не входит: исключения MPL-2.0 в `deny.toml` (решение пользователя: не трогать, понадобятся с Tauri); `packageExtensions` в `pnpm-workspace.yaml`; белый список лицензий.

## Целевое поведение [@for: all]
- `node scripts/check-npm-licenses.mjs packages/vendor` проходит и при `khroma@2.1.0 — Unknown` (CI), и при `MIT` (локально).
- Обновление khroma до другой версии снова роняет проверку: новая версия без уточнения — `Unknown`, а уточнение старой версии осталось без совпадения.

## Требования [@for: all]
- **FR-1:** В скрипте таблица уточнений по каталогу, переданному первым аргументом: `{"packages/vendor": {"khroma@2.1.0": "MIT"}}`, у записи — комментарий, где и когда проверена лицензия (файл `license` репозитория fabiospampinato/khroma, «The MIT License (MIT)», 2026-10-26).
- **FR-2:** Сверка вынесена в чистую экспортируемую функцию без запуска pnpm (вход — разобранный JSON `pnpm licenses list --json`, белый список, уточнения каталога; выход — нарушения и неиспользованные уточнения). Ключ пакета — `имя@версия`, каждая версия из `versions` отдельно. Пакет с лицензией вне белого списка проходит, только если для его ключа есть уточнение и уточнённая лицензия проходит `isAllowed`; иначе — нарушение `<каталог>: <имя>@<версия> — <лицензия pnpm>` (при уточнении вне белого списка — с припиской `(уточнено: <лицензия>)`). Пакеты с допустимой лицензией проверяются как раньше.
- **FR-3:** Уточнение каталога, ключа которого нет в выводе pnpm (ни под какой лицензией), — ошибка: `Уточнения без совпадения в <каталог> (обновите или удалите): <ключ>`. Нарушения и неиспользованные уточнения печатаются в stderr, код выхода 1; иначе вывода нет, код 0. Каталог без `package.json` пропускается, как раньше (его уточнения не проверяются).

## Данные, права, ошибки [@for: backend, security, qa]
- Скрипт читает только `deny.toml` и вывод `pnpm licenses list`; сеть и запись не добавляются. Уточнение — ручная проверка лицензии, поэтому привязано к точной версии.
- Ошибочное уточнение не может пропустить лицензию вне белого списка: уточнённое значение само проходит `isAllowed`.

## Карта реализации [@for: backend, frontend, qa]
- Backend: `scripts/check-npm-licenses.mjs` (infra).
- Frontend: не затрагивается.
- Новые тесты: `scripts/check-npm-licenses.test.mjs` — функция FR-2 на AC-1…AC-5 (входы — литералы в форме вывода pnpm).

## Критерии приёмки [@for: all]
### AC-1: Уточнение закрывает Unknown
- **Дано:** вывод `{"Unknown": [{"name": "khroma", "versions": ["2.1.0"]}], "MIT": [{"name": "a", "versions": ["1.0.0"]}]}`, уточнения `{"khroma@2.1.0": "MIT"}`.
- **Действие:** функция FR-2.
- **Ожидание:** нарушений нет, неиспользованных уточнений нет.

### AC-2: Новая версия снова на проверку
- **Дано:** вывод `{"Unknown": [{"name": "khroma", "versions": ["2.1.1"]}]}`, те же уточнения.
- **Действие:** функция FR-2.
- **Ожидание:** нарушение `khroma@2.1.1 — Unknown` и неиспользованное уточнение `khroma@2.1.0`.

### AC-3: Уточнение при уже известной лицензии
- **Дано:** вывод `{"MIT": [{"name": "khroma", "versions": ["2.1.0"]}]}` (локальный pnpm), те же уточнения.
- **Действие:** функция FR-2.
- **Ожидание:** нарушений нет, уточнение считается использованным.

### AC-4: Уточнение не обходит белый список
- **Дано:** вывод `{"Unknown": [{"name": "x", "versions": ["1.0.0", "2.0.0"]}]}`, уточнения `{"x@1.0.0": "GPL-3.0"}`.
- **Действие:** функция FR-2.
- **Ожидание:** два нарушения: `x@1.0.0 — Unknown (уточнено: GPL-3.0)` и `x@2.0.0 — Unknown`.

### AC-5: Без уточнений поведение прежнее
- **Дано:** вывод `{"Unknown": [{"name": "y", "versions": ["1.0.0"]}], "Apache-2.0": [{"name": "z", "versions": ["3.0.0"]}]}`, уточнений нет.
- **Действие:** функция FR-2.
- **Ожидание:** одно нарушение `y@1.0.0 — Unknown`.

### AC-6: Рецепты проекта
- **Дано:** рабочая копия с `packages/vendor/node_modules` после `just vendor`.
- **Действие:** `just npm-licenses`, `just lint`, `just test`; в каталоге `packages/vendor` — `pnpm licenses list --json`.
- **Ожидание:** все зелёные; в выводе pnpm есть `khroma` версии `2.1.0`.
