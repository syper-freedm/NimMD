# Итог задачи: Реализовать крейт nimmd-assets для безопасного чтения картинок

- Issue: #47
- Итоговое состояние: реализовано, все ворота пройдены

## Реализованные требования
- FR-1: крейт `crates/nimmd-assets` без зависимостей, член workspace, `#![forbid(unsafe_code)]`.
- FR-2: `read_asset(doc_path, href, &mut budget)` — URL-decode, отказ для схем, абсолютных путей и `~`, лексическая проверка `..` до обращения к ФС (`\` — разделитель на любой ОС), база — каталог канонического документа, `canonicalize` + проверка префикса, только `png jpg jpeg gif webp svg`.
- FR-3: `MAX_ASSET_BYTES` 5 МБ, `AssetBudget` 20 МБ по уникальным каноническим путям; повтор пути лимит не расходует.
- FR-4: `AssetError` с `Display` на русском и `std::error::Error`.
