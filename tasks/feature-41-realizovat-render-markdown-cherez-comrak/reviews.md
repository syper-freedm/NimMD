### Специалист по ИБ
- Статус: APPROVED

- ID: SEC-001
- Уровень: NOTICE
- Ссылка: FR-2 / FR-3 / AC-7
- Проблема: API3/XSS-контракт. comrak 0.56 при `unsafe_ = false` заменяет сырой HTML на `<!-- raw HTML omitted -->`, экранирует только `render.escape = true` (в FR-2 нет) — AC-7 (а), (б) «есть `&lt;`» не выполнится. `dangerous_url` пропускает `data:image/png|gif|jpeg|webp` и в `href`, не только в `src`.
- Требуемый результат: добавить `render.escape = true` в опции рендера; тест на `href` не требует запрета `data:image/*`.

- ID: SEC-002
- Уровень: NOTICE
- Ссылка: Данные, права, ошибки / FR-4
- Проблема: API4. Линейность подсветки syntect не гарантирована: регэкспы fancy-regex ограничены лишь пределом бэктрекинга на каждое совпадение; `render_fragment` сама не режет вход по `MAX_BYTES`.
- Требуемый результат: в бенчмарк Task 7 включить враждебный блок кода, размер входа контролирует хост.
