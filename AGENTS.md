## Git / Cloud Agent

Один разработчик: **не открывать pull request**.

- Финальная доставка — merge в `main` и push `main` (fast-forward или merge commit).
- Feature-ветки можно использовать локально; PR не создавать.
- После успешного merge в `main` remote feature-ветку можно удалить.
